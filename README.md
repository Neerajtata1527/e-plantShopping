# Paradise Nursery

Paradise Nursery is a React-based online plant shopping application where users can browse different categories of houseplants, add plants to a shopping cart, and manage their cart items.

## Features

- Paradise Nursery landing page
- Company information section
- Plant products organized into categories
- Add plants to the shopping cart
- Dynamic cart item count
- Increase and decrease item quantities
- Remove items from the cart
- Calculate individual item totals
- Calculate total cart amount
- Continue Shopping option
- Checkout functionality placeholder
- Redux Toolkit for global cart state management
- GitHub Pages deployment

## Technologies Used

- React
- Redux Toolkit
- React Redux
- JavaScript
- HTML
- CSS
- Vite
- GitHub Pages

## Project Structure

- `App.jsx` - Main application and landing page
- `AboutUs.jsx` - Company information
- `ProductList.jsx` - Plant products and shopping functionality
- `CartItem.jsx` - Shopping cart functionality
- `CartSlice.jsx` - Redux cart reducers
- `store.js` - Redux store configuration
- `App.css` - Landing page styling
- `main.jsx` - React entry point and Redux Provider
